# GBA RANGERS V1.0 页面验收清单

## 打开项目

1. 打开微信开发者工具。
2. 选择“导入项目”。
3. 项目目录选择 `D:\Codex项目\小程序`。
4. AppID 保持测试号或使用工具自动识别的 `touristappid`。
5. 点击“导入”，等待首页出现。

## 公开页面

依次查看底部的“首页”“赛事”“Players”“Yearbook”。重点确认皇家蓝视觉、历史赛事、球员数据和年鉴章节是否符合预期。

进入任意赛事详情。访客只能看到公开区域，看不到精确地点、集合时间、费用、内部备注和报名名单。

## 成员与报名

1. 进入“我的球队”。
2. 使用邀请码 `GBA2026` 提交加入申请。
3. 切换为“球员”演示身份。
4. 打开下一场赛事，进入内部报名。
5. 选择“参加”“待定”或“缺席”，再复制微信群名单。

## 管理功能

1. 在“我的球队”切换为“管理员”。
2. 进入管理中心，审核成员并绑定球员档案。
3. 创建赛事，分别检查保存草稿和发布。
4. 编辑赛事，检查截止报名和取消赛事。
5. 打开已结束赛事，录入实际出场、进球、助攻和比分。
6. 将助攻数设置得高于进球数，页面应阻止发布。
7. 比分全部留空时，赛事应显示“赛果待补”。
8. 在照片审核中检查通过、拒绝、隐藏、封面和精选操作。
