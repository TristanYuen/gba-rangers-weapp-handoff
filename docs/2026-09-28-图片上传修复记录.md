# 图片上传修复当前状态

## 用户确认的功能

保留上传须知。用户确认后打开相册或相机，头像可裁剪，比赛照片可多选，提交后等待队长审批。

## 当前修改

- 三个入口均恢复上传须知，确认按钮为“同意继续”，符合四字符上限。
- 撤掉“小程序尚未配置图片隐私声明，请联系管理员”这条自定义提示。该文字原先只在微信选图接口失败后显示，没有作为选图前置条件。
- 沿用修改前的chooseMedia接口。没有增加隐私授权开关，没有修改微信隐私校验设置。
- 保留防重复提交、微信对象错误识别、取消处理、压缩降级、批量部分成功反馈、已提交记录不因刷新失败而误报等修复。
- 原始接口错误仍记录在开发者工具控制台。

## 验证

13个测试文件、68项通过。类型检查、相关文件ESLint及小程序构建通过，导入目录已同步。

实际运行曾确认须知可以打开；确认后微信返回：

`chooseMedia:fail api scope is not declared in the privacy agreement`

继续检查时又出现云端响应超时。尚未证实相册恢复，也未验证真实图片上传和审批后的展示。不能以测试通过、改掉提示或模拟器局部通过作为正式版恢复的证明。

## 后续阻塞

微信公众平台后台尚未核实；浏览器工具明确禁止访问该站点，并禁止改用其他通道绕过。需要在用户自己的浏览器里核对对应AppID的用户隐私保护指引及图片接口声明，随后在正常网络下重新验证三个入口。

本次未上传、提交审核或发布正式版。
