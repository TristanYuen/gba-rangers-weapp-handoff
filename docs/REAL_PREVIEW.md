# 小程序真实效果检验方式

## 推荐验收链路

### 1. 微信开发者工具官方模拟器

双击项目根目录的 `打开小程序真实预览.cmd`。

首次使用时，脚本会打开微信开发者工具官方下载页面。安装完成后再次双击，脚本会直接导入并打开 GBA RANGERS 项目。

当前工程使用测试 AppID 和本地数据，可以检查：

- 小程序原生页面尺寸、字体和组件表现。
- 底部 TabBar、页面栈、返回和跳转。
- 输入框、开关、选择器、弹窗和剪贴板。
- Visitor、Player、Admin、Owner 四种演示权限。
- 报名、候补、赛后统计、照片审核和管理中心。

### 2. 微信真机预览

正式 AppID 提供后，在开发者工具中点击“预览”，使用微信扫码。真机用于确认：

- 不同手机尺寸和安全区域。
- 微信授权、订阅消息、相册和相机。
- 弱网、上传失败、加载速度和实际触控体验。

### 3. 发布前真机调试

CloudBase 环境接入后，再使用“真机调试”检查云函数、数据库权限、媒体上传和订阅消息。最终验收至少覆盖一台 iPhone 和一台 Android 手机。

## 验收结论标准

官方模拟器通过后，可以确认页面结构和微信组件表现。真机预览通过后，才能确认实际使用效果。网页版手机框适合快速讨论视觉方案，不作为最终发布验收依据。
