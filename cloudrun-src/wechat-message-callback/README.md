# 微信消息推送回调服务

该服务部署到微信云托管，供微信后台“开发→开发管理→消息推送”填写URL。

注意：微信云开发环境和微信云托管服务是两个层次。已有`cloud1`环境可以复用，但仍需在该环境的“云托管”中创建服务并开启公网访问。

## 云托管服务设置

1. 在环境`cloud1`的“云托管”中新建服务，部署目录选择本目录，或使用本目录构建镜像。
2. 开启公网访问，关闭HTTP网关鉴权。
3. 服务端口使用`3000`。
4. 配置环境变量：

   - `CLOUDBASE_ENV_ID=cloud1-d4g1nl8yx26d1f3f2`
   - `WECHAT_PUSH_TOKEN=<自行设置并私下保存的随机Token>`

5. 部署后访问`https://云托管默认域名/healthz`，返回`ok`才继续配置微信后台。

## 微信后台填写

- URL：`https://云托管默认域名/api/wechat/message`
- Token：与`WECHAT_PUSH_TOKEN`完全一致
- EncodingAESKey：点击“随机生成”，只保存到微信后台和安全密码管理器
- 消息加密方式：明文模式
- 数据格式：XML

服务处理`subscribe_msg_sent_event`并更新`notice_recipients`，同时处理用户拒绝订阅后的额度失效事件。确认URL后，微信后台会先发GET验证请求，服务必须原样返回`echostr`。

当前服务只实现明文XML模式。微信后台必须选择“明文模式”和“XML”；选择兼容模式或安全模式前，需要先补齐官方消息加解密流程，不能直接切换。
