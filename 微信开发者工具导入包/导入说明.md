# 微信开发者工具导入说明

1. 打开微信开发者工具。
2. 点击“导入项目”。
3. 选择当前文件夹“微信开发者工具导入包”，请勿单独选择 `miniprogram` 文件夹。
4. AppID 已配置为 `wx5ded6945b59deb10`，使用该 AppID 对应的微信账号登录。
5. 点击“导入”，等待首次编译完成。

开发调试前可在项目根目录运行 `pnpm package:weapp`，该命令会重新构建并同步当前导入包，避免打开旧版本文件。

项目默认使用本地演示数据，查看页面不依赖云开发环境。`cloudfunctions` 文件夹已一并整理，可在后续接入云开发环境时使用。

如果模拟器仍显示长时间无响应，请在微信开发者工具中依次执行：

1. “工具”→“清除缓存”→“清除全部缓存”。
2. 关闭当前项目。
3. 重新导入当前文件夹。

本项目已关闭“热重载”，降低开发者工具首次启动时的模拟器负担。
